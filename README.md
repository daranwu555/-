# 風險傳導鏈

用五個總經指標,看懂市場從資金緊縮到恐慌的傳導順序。互動式教材,含 2000 年至今的真實數據。

| 章節 | 指標 | 傳導層 |
|---|---|---|
| 01 | 美元指數 DXY 與實質利率 | 資金面 |
| 02 | 信用利差 | 信用面 |
| 03 | 金銀比 | 風險偏好 |
| 04 | 槓桿 ETF 金絲雀 | 股市內部 |
| 05 | VIX 期限結構 | 恐慌 |

另有「危機回放」(7 次歷史危機的亮燈順序)與「目前狀態」(依最新數據判讀)。

## 使用方式

直接用瀏覽器開啟 `index.html` 需要透過本機伺服器(瀏覽器會擋本機檔案讀取):

```bash
python -m http.server 8765
```

然後打開 http://localhost:8765 。

## 更新數據

```bash
python update_data.py
```

從 FRED 與 Yahoo Finance 下載最新日資料,覆寫 `data/data.js`。只用 Python 標準函式庫。
